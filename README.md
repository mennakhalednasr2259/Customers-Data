# Customers Data

مشروع تدريبي مستقل مبني باستخدام Nuxt 2 وVue 2 وVuetify. صفحة العملاء مستوحاة من صفحة العملاء في TeamPulse، لكن البيانات والعمليات محلية بالكامل ولا يوجد اتصال بـ API.

## التشغيل

1. افتحي الطرفية داخل هذا المجلد.
2. ثبتي الحزم بالأمر npm install.
3. شغلي نسخة التطوير بالأمر npm run dev.
4. افتحي عنوان localhost الذي يظهر في الطرفية.

## الوظائف

- البحث بالاسم أو الهاتف وأربعة فلاتر للعملاء.
- جدول العملاء مع الترقيم والتنقل بين الصفحات.
- إضافة وتعديل وعرض وحذف مع تأكيد قبل الحذف.
- تنزيل قالب Excel واستيراد XLSX/CSV وتصدير XLSX.
- ترجمة عربية وإنجليزية مع اتجاه تلقائي RTL/LTR.
- حفظ العملاء واللغة وتفضيل المظهر في Local Storage داخل المتصفح.

كل البيانات تجريبية ومحلية على الجهاز الحالي. لا يوجد Backend أو API أو مزامنة بين الأجهزة.
